# Rosarium

Página estática para rezar o rosário em latim, com tradução para o português.

## Como executar

Na raiz do projeto, inicie um servidor HTTP local:

```bash
python -m http.server 8000
```

Acesse [http://localhost:8000](http://localhost:8000) no navegador.

## Estrutura principal

- `index.html`: página principal.
- `rosarium.md`: orações e mistérios em latim e português.
- `style.css`: estilos e layout responsivo.
